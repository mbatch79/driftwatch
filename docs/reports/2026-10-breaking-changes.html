How this was produced. A deterministic pipeline pulled each vendor's own machine-readable spec from its GitHub repository, structurally diffed consecutive commits (endpoints, parameters, request and response fields, schema types, enums, deprecation flags) and classified each change. A second, independent step re-located every finding in the raw spec from its locator alone; anything it could not reproduce was discarded. No language model was involved in detection or verification.

OpenAPI findings are exact. AWS and Shopify entries come from release-note changelogs and are keyword-classified: the quoted line is verified to exist, the severity is a heuristic, and they're marked. Specs track each vendor's newest API version, so "removed" means removed in the newest version; check against the version you pin.
